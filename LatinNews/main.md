# Техническое задание: новостной портал на React

## 1. Цель проекта

Создать React-приложение, которое получает публикации из API JSONPlaceholder и отображает их в виде новостной ленты.

API:

```text
https://jsonplaceholder.typicode.com/posts
```

JSONPlaceholder не является настоящей новостной API. Она предоставляет тестовые публикации, которые в рамках задания нужно представить как новости.

---

## 2. Формат данных

Одна публикация выглядит примерно так:

```json
{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
  "body": "quia et suscipit..."
}
```

Описание полей:

- `userId` — ID пользователя, который создал публикацию;
- `id` — ID публикации;
- `title` — заголовок;
- `body` — текст публикации.

---

## 3. Основной функционал

### 3.1. Загрузка публикаций

После запуска приложения необходимо отправить GET-запрос:

```text
GET https://jsonplaceholder.typicode.com/posts
```

Полученные публикации нужно сохранить в состоянии React и отобразить на странице.

Для запроса можно использовать обычный `fetch`.

Пример:

```js
fetch('https://jsonplaceholder.typicode.com/posts')
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });
```

---

### 3.2. Карточка публикации

Каждая публикация должна отображаться в отдельной карточке.

В карточке необходимо показать:

- заголовок;
- текст публикации;
- ID публикации;
- ID пользователя;
- кнопку `Подробнее`.

Пример:

```text
Новость №1

Заголовок новости

Текст новости...

Автор: пользователь 1

[Подробнее]
```

Для карточки нужно создать отдельный компонент:

```text
PostCard
```

Компонент должен получать публикацию через `props`:

```jsx
<PostCard post={post} />
```

---

### 3.3. Состояние загрузки

Пока публикации загружаются, необходимо показывать сообщение:

```text
Загрузка новостей...
```

Пример состояния:

```js
const [isLoading, setIsLoading] = useState(true);
```

---

### 3.4. Обработка ошибки

Если запрос завершился ошибкой, нужно показать сообщение:

```text
Не удалось загрузить новости
```

Пример состояния:

```js
const [error, setError] = useState('');
```

Пример обработки запроса:

```js
fetch('https://jsonplaceholder.typicode.com/posts')
  .then(response => {
    if (!response.ok) {
      throw new Error('Ошибка загрузки');
    }

    return response.json();
  })
  .then(data => {
    setPosts(data);
  })
  .catch(() => {
    setError('Не удалось загрузить новости');
  })
  .finally(() => {
    setIsLoading(false);
  });
```

## 4. Поиск по публикациям

Добавить поле поиска.

Пользователь должен иметь возможность искать публикации:

- по заголовку;
- по тексту публикации.

Пример:

```text
[Введите запрос...]
```

Если пользователь ввёл `sunt`, нужно показывать только публикации, в которых это слово есть в заголовке или тексте.

Состояние поиска:

```js
const [search, setSearch] = useState('');
```

Пример фильтрации:

```js
const filteredPosts = posts.filter(post => {
  const title = post.title.toLowerCase();
  const body = post.body.toLowerCase();
  const query = search.toLowerCase();

  return title.includes(query) || body.includes(query);
});
```

## 5. Пагинация

Всего API возвращает 100 публикаций.

Необходимо показывать по 10 публикаций на одной странице.

Добавить кнопки:

```text
[Предыдущая] [Следующая]
```

Состояние текущей страницы:

```js
const [currentPage, setCurrentPage] = useState(1);
```

Количество публикаций на странице:

```js
const postsPerPage = 10;
```

Расчёт публикаций для текущей страницы:

```js
const lastPostIndex = currentPage * postsPerPage;
const firstPostIndex = lastPostIndex - postsPerPage;

const currentPosts = filteredPosts.slice(
  firstPostIndex,
  lastPostIndex
);
```

Количество страниц:

```js
const totalPages = Math.ceil(
  filteredPosts.length / postsPerPage
);
```

### Требования к кнопкам

Кнопка `Предыдущая` должна быть отключена на первой странице.

Кнопка `Следующая` должна быть отключена на последней странице.

Пример:

```jsx
<button
  disabled={currentPage === 1}
  onClick={() => setCurrentPage(currentPage - 1)}
>
  Предыдущая
</button>

<button
  disabled={currentPage === totalPages}
  onClick={() => setCurrentPage(currentPage + 1)}
>
  Следующая
</button>
```

## 6. Просмотр подробной публикации

При нажатии на кнопку `Подробнее` необходимо показать полную информацию о публикации.

На странице подробностей должны отображаться:

- полный заголовок;
- полный текст;
- ID публикации;
- ID пользователя;
- кнопка `Назад к новостям`.

Для первой версии можно не использовать React Router.

Выбранную публикацию можно хранить в состоянии:

```js
const [selectedPost, setSelectedPost] = useState(null);
```

Если `selectedPost` равен `null`, показывается список публикаций.

Если `selectedPost` содержит публикацию, показывается страница подробностей.

Пример:

```jsx
{selectedPost ? (
  <PostDetails
    post={selectedPost}
    onBack={() => setSelectedPost(null)}
  />
) : (
  <PostList
    posts={currentPosts}
    onSelectPost={setSelectedPost}
  />
)}
```

## 12. Дополнительное задание

```text
https://jsonplaceholder.typicode.com/users/1
```

```js
https://jsonplaceholder.typicode.com/users/${post.userId}
```

```json
{
  "id": 1,
  "name": "Leanne Graham",
```

- email;

Проект считается выполненным, если:

- публикации загружаются из API;
- отображается сообщение во время загрузки;
- отображается сообщение при ошибке;
- публикации выводятся в виде карточек;
- работает поиск;
- работает пагинация;

- можно вернуться к списку публикаций;

- данные передаются через `props`;
- используются `useState` и `useEffect`;
- приложение нормально выглядит на компьютере и телефоне.
